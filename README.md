# BeautyScale

Готовый сервис-маркетплейс для продажи курсов бьюти-мастеров:
- роли: ученик, преподаватель, админ;
- публикация курсов и уроков;
- покупка курсов и личный кабинет ученика;
- автоматический расчет комиссии платформы (ваш процент с каждой продажи);
- дашборд преподавателя (оборот/комиссия/выплата) и админ-дашборд.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:3000`.

## Переменные окружения

Создайте `.env`:

```env
PORT=3000
SESSION_SECRET=super-secret
PLATFORM_COMMISSION_RATE=0.2
ADMIN_EMAIL=admin@beauty.local
ADMIN_PASSWORD=admin123
```

- `PLATFORM_COMMISSION_RATE=0.2` = 20% платформе, 80% преподавателю.

## Railway Deploy

1. Создайте проект в Railway и подключите репозиторий.
2. Railway автоматически запустит `npm install` и `npm start`.
3. Добавьте переменные окружения из секции выше.
4. Для сохранения SQLite-базы между деплоями подключите Volume и укажите persistent storage для папки `src/data`.

## Дефолтный админ

Если в БД нет админа, он создастся автоматически по переменным `ADMIN_EMAIL/ADMIN_PASSWORD`.
