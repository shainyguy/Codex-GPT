# BeautyScale

Платформа для обучения и продажи курсов бьюти-мастеров.

## Реализованная карта страниц

- Главная: hero + поиск, категории, популярные курсы, топ мастера, до/после, отзывы, CTA.
- Каталог/поиск: фильтры по категории, уровню, языку, цене, рейтингу.
- Страница курса: описание, программа, отзывы, автор, покупка, похожие курсы.
- Мастера: список мастеров + публичный профиль.
- Авторизация: регистрация, вход, восстановление пароля.
- Кабинет ученика: мои курсы, прогресс, домашки, сертификаты, избранное, история покупок, настройки.
- Кабинет мастера: курсы, создание/редактирование, ученики, проверка домашек, аналитика, финансы, вебинары, профиль.
- Чат/сообщения, уведомления.
- Статические страницы: О платформе, FAQ, Блог, Политика, Соглашение.
- Админка: модерация, пользователи, финансы, жалобы, аналитика.
- Страница статуса ТЗ: `/spec`.

## MVP функции

- Профиль мастера = портфолио (опыт, сертификаты, соцсети, описание работ).
- Конструктор курсов: модули/уроки, видео/текст, материалы PDF/text, drag&drop сортировка уроков.
- Домашка: задания + отправка и проверка с фидбеком.
- Оплата через YooKassa (или demo fallback без ключей).
- Checkout-страница с промокодом `WELCOME10` (10%).
- Комиссия платформы и доля мастера сохраняются в покупках.
- Возврат в течение 14 дней.
- Базовая защита контента: доступ только после покупки, watermark, лимит устройств.

## Запуск

```bash
npm install
npm run dev
```

## Переменные окружения

```env
PORT=3000
SESSION_SECRET=super-secret
PLATFORM_COMMISSION_RATE=0.2
ADMIN_EMAIL=admin@beauty.local
ADMIN_PASSWORD=admin123
DATA_DIR=./src/data
YOOKASSA_SHOP_ID=
YOOKASSA_SECRET_KEY=
```

## Railway

1. Подключите репозиторий.
2. Добавьте переменные окружения.
3. Подключите Volume.
4. Укажите `DATA_DIR=/data` (или путь вашего volume).

## Ограничения MVP

- Enterprise DRM и реальный оффлайн-просмотр не реализованы в текущей версии.
- Для загрузки файлов в production рекомендуется S3/R2.
