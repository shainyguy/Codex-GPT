# Соль Перец — сайт + CRM + доставка

Полноценный минималистичный сайт кафе с меню, корзиной, заявками, отзывами и CRM-админкой.

## Запуск
```bash
python app.py
```

Откроется на `http://127.0.0.1:5000`.

## Что есть
- Главная с hero, блоками «О нас», «Банкеты», калькулятором и контактами.
- Яндекс Карты в контактах.
- Отдельная страница меню со всеми категориями и блюдами.
- Блюдо дня, комбо-наборы, калорийность, аллергены, время приготовления.
- Корзина и оформление заказа (доставка по Сходне = 0 ₽).
- Ограничение на доставку бара (алкоголь нельзя на доставку по РФ).
- Отправка заказов и заявок в Telegram.
- Поддержка редиректа в ЮKassa (если заданы ключи).
- CRM: новые заказы, смена статуса, связь с заказчиком, модерация отзывов.

## Админка
- URL: `/admin`
- По умолчанию: `admin / admin123`
- Настраивается через переменные:
  - `ADMIN_USERNAME`
  - `ADMIN_PASSWORD`
  - `ADMIN_TOKEN`

## Интеграции
- Telegram:
  - `TELEGRAM_BOT_TOKEN`
  - `TELEGRAM_CHAT_ID`
- ЮKassa:
  - `YOOKASSA_SHOP_ID`
  - `YOOKASSA_SECRET_KEY`

## Как добавлять новые блюда и фото
1. Откройте `data/menu.json`.
2. Добавьте категорию в `categories` или позицию в `items`.
3. Для каждой категории можно задать `image` (ссылка на фото).
4. Для алкогольных товаров добавляйте `"isBar": true` — это блокирует доставку.
