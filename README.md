# Freelance Radar Bot

Telegram-бот «Ловец жирных заказов» — агрегатор фриланс-заказов с мгновенными уведомлениями, генерацией отклика через GigaChat, оплатой подписки через ЮKassa и мини-приложением в стиле 2025-2026.

## Возможности
- Выбор категорий (`Design`, `Python`) прямо в боте.
- Мониторинг источников (HH API, Habr Career RSS, Telegram/RSS-фиды + расширяемые коннекторы Kwork/FL).
- Мгновенные уведомления о новых заказах.
- Кнопка «Сгенерировать отклик» (GigaChat).
- 3 дня бесплатного триала.
- Подписка 690₽/месяц через ЮKassa.
- Мини-приложение (`index.html`) для презентации/лендинга.
- Готовность к деплою на Railway.

## Быстрый старт
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app.main
```

## Переменные окружения
См. `.env.example`.

## Railway
- `Procfile` запускает API и бота одним процессом.
- Добавьте переменные окружения в Railway Variables.
- Публичный URL укажите в `PUBLIC_BASE_URL`.

## Важно
Некоторые биржи не предоставляют открытые API. В проекте предусмотрена архитектура источников и готовые адаптеры, а для закрытых площадок оставлены расширяемые заглушки (`KworkSource`, `FLSource`) с безопасным fallback.
