# BeautyScale

Минималистичный маркетплейс курсов для бьюти-мастеров (светлый дизайн), готовый к Railway.

## Что уже реализовано (MVP)

- Роли: ученик / преподаватель / админ.
- Профиль мастера (портфолио): специализация, опыт, сертификаты, соцсети.
- Каталог с фильтрами: категория, уровень, язык, цена, рейтинг.
- Конструктор курса:
  - модули и уроки,
  - видео + текст,
  - материалы PDF/текст,
  - домашние задания,
  - drag & drop сортировка уроков.
- Оплата:
  - интеграция с YooKassa (если заданы ключи),
  - demo-режим оплаты без ключей,
  - хранение комиссии платформы и доли преподавателя,
  - возврат в течение 14 дней.
- Защита контента (базовая): лимит 2 устройств + watermark имени покупателя на просмотре урока.
- Отзывы и рейтинг мастеров.

## Запуск

```bash
npm install
npm run dev
```

## .env

```env
PORT=3000
SESSION_SECRET=super-secret
PLATFORM_COMMISSION_RATE=0.2
ADMIN_EMAIL=admin@beauty.local
ADMIN_PASSWORD=admin123
DATA_DIR=./src/data
YOOKASSA_SHOP_ID=
YOOKASSA_SECRET_KEY=
```

## Railway

1. Подключите репозиторий в Railway.
2. Добавьте переменные окружения из `.env`.
3. Подключите Volume.
4. Укажите `DATA_DIR` на путь volume (например, `/data`).

## Важно

- Для полноценной загрузки видео/PDF в production лучше подключить S3/Cloudflare R2.
- DRM-стриминг в текущей версии не реализован на уровне enterprise DRM, только базовая защита доступа.
